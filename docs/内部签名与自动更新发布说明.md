# Perovskite Engine 内部签名与自动更新

## 当前信任身份

- 发布者：CN=Perovskite Engine Internal
- 证书 SHA-256：

~~~
12925004ec1ef5a92077a88b40140e2a63115d011a1332e5f3cfe0732d5c2135
~~~

PFX 文件包含私钥，只保存在发布者电脑，不提交 GitHub，也不发给实验室用户。

## 内部签名构建

在生成证书的同一 Windows 用户终端中执行：

~~~powershell
powershell -ExecutionPolicy Bypass -File scripts\build_release.ps1 -Version 1.4.2 -Mode InternalSigned -SignToolPath "F:\Windows Kits\10\bin\10.0.22621.0\x64\signtool.exe" -CertificateFile "certificates\internal-20261104\PerovskiteEngine-Internal.cer"
~~~

发布目录会生成：

- PerovskiteEngine-Setup-<版本>.exe
- 同名 .sha256
- release-manifest.json
- release-manifest.json.sig
- PerovskiteEngine-Internal.cer

开发测试可以使用 -Mode Development，但开发包不能作为正式更新包发布。

## 实验室电脑安装公钥证书

只把以下 .cer 发给实验室用户：

~~~
certificates\internal-20261104\PerovskiteEngine-Internal.cer
~~~

在 PowerShell 中执行：

~~~powershell
$cer = "PerovskiteEngine-Internal.cer"
Import-Certificate -FilePath $cer -CertStoreLocation "Cert:\CurrentUser\TrustedPublisher"
Import-Certificate -FilePath $cer -CertStoreLocation "Cert:\CurrentUser\Root"
~~~

安装后，Windows 可以验证内部签名。自签名证书仍可能触发 SmartScreen 提示，这是正常现象；该证书只适合实验室内部使用。
